Employee Salary Prediction System

## Project Overview

Employee Salary Prediction System is a Machine Learning based web application that predicts employee salaries based on professional factors such as age, education, job role, gender, and years of experience.

The project includes complete machine learning workflow from data preprocessing, model training, evaluation, and deployment using Flask.

---

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-Learn
- Flask
- HTML
- CSS
- Joblib
- Render Deployment

---

## Machine Learning Algorithm

Random Forest Regressor

The Random Forest model was selected because it handles non-linear relationships and provides better prediction accuracy using multiple decision trees.

---

## Project Workflow

1. Data Collection

Used employee salary dataset containing:
- Age
- Gender
- Education Level
- Job Title
- Years of Experience
- Salary


2. Data Cleaning

- Removed missing values
- Checked duplicate records
- Converted categorical data


3. Feature Engineering

Categorical columns converted using Label Encoding:

- Gender
- Education Level
- Job Title


4. Model Training

Algorithm:

Random Forest Regression


5. Model Evaluation

Metrics:

- R² Score
- Mean Absolute Error
- Mean Squared Error


6. Deployment

- Developed Flask web application
- Saved ML model using Joblib
- Hosted application on Render cloud platform
